## Download / ดาวน์โหลด

Download **AppMixer-v…-macOS-universal.zip** below. Supports Apple Silicon and Intel Macs running macOS 14.2 or later. You do not need Xcode.

ดาวน์โหลด **AppMixer-v…-macOS-universal.zip** ด้านล่าง รองรับทั้ง Apple Silicon และ Intel บน macOS 14.2 ขึ้นไป ไม่ต้องติดตั้ง Xcode

1. Extract the ZIP, then drag AppMixer.app into Applications.
2. Open AppMixer and click the sliders icon in the menu bar.
3. Enable Per-app and grant system audio access when prompted.

1. แตก ZIP แล้วลาก AppMixer.app ไปที่ Applications
2. เปิดแอปและคลิกไอคอนตัวปรับเสียงบนแถบเมนู
3. เปิดสวิตช์แยกแอป และอนุญาตการเข้าถึงเสียงระบบเมื่อ macOS ขอ

## Features / ความสามารถ

- Master volume and mute / ปรับเสียงรวมและ mute
- Per-app volume with app names and icons / ปรับเสียงแยกแอปพร้อมชื่อและโลโก้
- Output and microphone device selection / เลือกอุปกรณ์เสียงออกและไมโครโฟน
- Thai and English / ภาษาไทยและอังกฤษ

## Prototype / รุ่นทดลอง

This build is ad-hoc signed and **not notarized by Apple**. macOS may block the first launch. For this trusted download, use System Settings → Privacy & Security → Open Anyway if offered. Do not disable Gatekeeper. Audio routing, Bluetooth, and sleep/wake compatibility remain experimental.

รุ่นนี้เซ็นแบบ ad-hoc และ **ยังไม่ผ่านการ notarize จาก Apple** macOS อาจบล็อกการเปิดครั้งแรก หากเชื่อถือไฟล์จาก repository นี้ ให้ใช้ System Settings → Privacy & Security → Open Anyway หากมีตัวเลือก ไม่ต้องปิด Gatekeeper การทำงานกับอุปกรณ์เสียง Bluetooth และการ sleep/wake ยังเป็นรุ่นทดลอง
