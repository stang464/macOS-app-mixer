01 / THE CONTROLS

Make your sound fit your workflow

One place to control individual app levels and your Mac’s default audio devices.

☷

Less music. More meeting.

Adjust volume and mute independently. Settings are saved by app bundle identifier. On the next launch, enable Per-app to apply your saved levels.

◖

Master follows your Mac

Change overall output volume without changing individual app settings. AppMixer reads macOS volume every second, including keyboard and Control Center changes.

⇄

Choose output and microphone

Change your Mac’s default devices from the app. Lists refresh every second. Selecting a microphone changes the default input only — it does not record audio.

▦

Recognizes the apps you use

Reads real names and icons from installed apps, groups helpers within the same app bundle, and filters system thumbnail services out of the list.

⌁

At 100%, original audio flows

An unmuted app at 100% uses its original output directly. Turning Per-app off stops audio routes and collapses the control panel.

TH / EN

Two languages. Your choice saved.

The native app starts in Thai. Switch to English instantly in settings, including labels, status messages, errors, and accessibility text.

03 / UNDER THE HOOD

Native, from interface to audio path

SwiftUI MenuBarExtra powers the interface. Core Audio Process Taps capture per-app audio, then a C audio kernel adjusts gain and sends it to the current output device.

App process→Process tap→C gain kernel→Output

The kernel uses atomics for gain changes and ramps the level, with no memory allocation or Swift calls on the audio thread.

04 / BEFORE YOU INSTALL

Know the limits before you install

How ready is this version?

The local source is v0.4.2, a prototype for macOS 14.2 and later. It includes a universal binary for Apple Silicon and Intel, but the README states that Intel hardware has not been tested. Bluetooth, meeting apps, and sleep/wake still need real-world testing.

Why might macOS block the first launch?

The app is ad-hoc signed and not notarized by Apple. If you trust the download, follow Apple’s instructions and use System Settings → Privacy & Security → Open Anyway when available. Do not disable Gatekeeper.

Does it support every audio format and device?

Supports Float32 mono/stereo on the output device’s first stream. Surround sound, per-app output routing, and levels above 100% are not supported. Some HDMI, DisplayPort, and DAC devices require their own hardware volume controls.

How does device selection affect other apps?

It changes the macOS default device, and that selection remains after AppMixer quits. Meeting apps with their own device settings may need separate changes. Changing output recreates per-app routes and may briefly restore original audio levels. A Bluetooth microphone can also affect output quality.

What does the code test?

C tests cover attenuation, mute ramps, planar/interleaved stereo, mono, missing data, and hardware-input exclusion with AddressSanitizer and UndefinedBehaviorSanitizer. Swift tests cover app identity, thumbnail filtering, Thai/English translations, and invalid device IDs. These tests do not verify physical audio output or live device switching.

Is audio recorded or uploaded?

The README states that audio is processed locally in memory and is not saved or uploaded. Selecting a microphone only changes the system’s default input device. AppMixer does not capture or record microphone audio.
